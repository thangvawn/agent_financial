# Heatmap HM-01–HM-06 — fixed and verified, 02/11/2026

All six findings from the [logic review](MARKET_HEATMAP_LOGIC_REVIEW_2026_11_02.md) are resolved in the workspace. The one-map layout, actual weights and user-approved orange/red–yellow–green palette remain.

## Changes

- **HM-01:** SSI rejects the whole batch when any requested exchange times out, returns empty data or an invalid payload. Every provider/fallback must cover the exchanges in the universe before its snapshot is accepted; a second check at the cache-write boundary compares against the existing cache. Incomplete candidates cannot overwrite the last complete snapshot. A valid complete fallback is accepted; otherwise the complete cache is returned as stale. Cold start with only partial candidates returns degraded/empty, not fresh partial data. Quotes from different refreshes are not merged.
- **HM-02:** GTGD/capitalization use đồng, triệu đồng or tỷ according to value; small volumes use actual CP. PFL150,000 VND now reads `150.000 đ`, ACE100 shares reads `100 CP`. The123 GTGD and341 volume rows previously rounded to0 no longer do so. Tiny nonzero percentage changes also retain meaningful digits.
- **HM-03:** When a new layout arrives, the camera preserves the selected ticker's visible point, or the inspected center point after a manual pan. The selected label retains a readable scale and the pinned quote remains. If the selected stock disappears, return to overview. Metric/filter/viewport changes reset camera state instead of reviving a previous scope's zoom.
- **HM-04:** Capture starts on pointerdown at the cell; normal cell clicks still reach that cell. Pointerup, cancellation, lost capture, window blur and hidden-tab cleanup end the gesture. A mouse event with no held buttons cannot continue panning.
- **HM-05:** Layout has an explicit retry generation. Top-level refresh restarts layout even when the data is unchanged; the error state also has a dedicated layout-retry button. Superseded workers and timers are cleaned up.
- **HM-06:** Drag suppression consumes the following pointer click only; keyboard-generated clicks remain enabled.
