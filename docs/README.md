# Project Documentation

Thư mục này chứa tài liệu không phải source code.

## Quy ước

- `project/`: worklog, ghi chú vận hành, quyết định sản phẩm, review nội bộ.
- `research/`: tài liệu nghiên cứu, proposal, đề cương, tài liệu Word/PDF.
- `architecture/`: thêm khi cần ADR, sơ đồ hệ thống, chuẩn module.
- `operations/`: thêm khi cần runbook deploy, backup, data refresh.

Không đặt tài liệu rời ở root repo trừ `README.md`, `CHANGELOG.md`, `LICENSE` hoặc file cấu hình chuẩn.
